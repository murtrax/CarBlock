CarBlock

CarBlock is a MERN stack application implemented alongside a private ethereum blockchain that will generate and record traceable and tamper-proof vehicle history reports alongside a spare part verification system.

Registration Authority Use-Case
1-	Add a new vehicle into the system
2-	Transfer ownership of a vehicle
3-	Approve/Decline pending workshop request.
4-	Generate alerts for attempts at malicious activities in the system. 

Workshop/Garage owner Use-Case
1-	Add new service history records of a vehicle
2-	Add spare parts into a vehicle
3-	Add new accident history records of a vehicle

General User Use-Case
1-	Generate a vehicle history report through a Registration or VIN number.
